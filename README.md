In all the flex assignments, having to make page-level filters took a lot more steps and was not easily changeable. With the dashes in PowerBI, it was as simple as moving the filter into the page section and adding the condition there. Another item I would implement into my dashboard if I were to use PowerBI instead would be the drill-down features. Certain visuals could drill sections into subsections. Previously, each subsection would have its own visual, making it harder to draw comparisons.

These three tools offer very valuable information, but the main ones that help explain data is excel and PowerBI. For initial data exploration and behind the scenes work, I would use excel as data functions are something that I am accustomed to and can easily interpret. When I want to show my finds, I would use a PowerBI dashboard to give to the client.
